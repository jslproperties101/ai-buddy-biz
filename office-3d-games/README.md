# 3D Futuristic Office Games

Two 3D office games (one floor, every department, staff Relax Room with futuristic gadgets):

- **NovaCorp HQ** — Opus edition (`site/opus/`)
- **Fable Dynamics HQ** — Fable edition (`site/fable/`)

Every push to the `games/office-3d-games` branch builds:
- **Android APKs** for both games → *Releases* (latest build)
- Website: the `site/` folder (open `site/index.html`)
